# SDF-campaign dev probes

Regression net beyond the ctest suites — see `../../../doc/` and the suite's
`docs/archive/ANALYTIC_SDF_GEOMETRY.md` for what each gates.

**Provenance.** These lived as `suite/.sdf-campaign-probes/` (untracked, a session-independent
copy) from the analytic-SDF geometry campaign, 2026-08-29 .. 09-02. They moved here on 2026-09-22
and are now TRACKED, closing the umbrella `docs/QUALITY_PLAN.md` item that asked for exactly this
move: nine tracked documents cite these gates and their measured numbers, so a fresh clone had
references to files it did not have. If you are following a link that says `.sdf-campaign-probes/`,
this is the directory it means.

The captured `before_*.bin` / `mask6_before.npy` / `np*.npz` comparison artifacts are NOT tracked
(`.gitignore`): they are regenerated by the probes that write them. Everything that carries a
reference VALUE carries it in the source or in this README, not in a binary.

Paths in the notes below are relative to this directory; run them from the flow repo root with the
build on `PYTHONPATH`.

## Layer 0-2 (geometry, scene)
- flow_probe.py         flow physics fingerprint; u_sum MUST be 6.74193610583927948e+05.
                        **RUN AT 4 OpenMP THREADS.** p_sum and u_l2 (and, at high thread counts,
                        u_sum's last digits) are thread-count sensitive in flow's host reductions —
                        pre-existing, not a regression signal.
                        (PYTHONPATH=<flow build> OMP_PROC_BIND=false OMP_NUM_THREADS=4 python …)
- scene_check.py        3-way geometry agreement: sampled array == 108-image scene == native
                        periodic scene, + scene crossings finite
- setsolid_bench.py     set_solid rebuild cost split (Layer-3 datum: 339 ms @128^3 host, 65/35)
- time_setsolid.py      AMR RCP acceptance driver (depth N; needs core/python/build_cuda2)
- mpi_scene_gate.py     Layer-2 MPI scene demo AND Layer-4 rung 4. Run under mpirun at np=1,2,4,
                        then `--compare`. Claims: per-rank cut owner == the single-rank global
                        field restricted to the block (0 mismatches), k identical, resolved
                        per-instance force equal to 4e-07 (atomics, so not bitwise).

## Layer 3 (moving geometry)
- owner_gate.py         cut ownership vs a numpy brute-force argmin on the 4-sphere bed
- galilean_gate.py      THE rung-2/3 gate. u_B + V == u_A between a lab and a boosted frame, run
                        with the wall-flux term ON and OFF so its absence is exhibited, not
                        asserted. Also prints the integrated force in both frames — force is
                        frame-invariant, and that check is what caught the masked-solid bug.
                        GAL_STEPS=<n> to vary the solver work (the ON error falls with it; the
                        OFF error does not).
- rotlet_gate.py        spinning sphere vs the analytic rotlet. **Only decidable at R/L <~ 0.05**;
                        above that the naive periodic image sum dominates. ROTLET_MODE=refprobe
                        is the experiment that establishes which (R fixed in CELLS, box varying).
                        ROTLET_RF, ROTLET_CROSSINGS, ROTLET_IMAGES.
- moving_step_bench.py  `march` = a translating sphere actually moves and drags fluid across 40
                        rebuilds; `bench` = ms/step static vs moving vs moving+rebuild. A BODY
                        FORCE IS ESSENTIAL in the bench or the static baseline solves nothing.

## Layer 4 (resolved CFD-DEM)
- force_gate.py         BOTH force evaluations against the momentum balance. The REACTION
                        (route b, the coupling force) must satisfy sum F = f*N_fluid to the
                        unsteady tail + solver residual — measured -8.8e-15 at 1600 steps; a
                        percent-level miss means a budget term is missing (that is what this gate
                        now checks). The traction (diagnostic) stays ~29% low by construction and
                        is printed alongside so the inconsistency stays visible.
- settling_gate.py      settling sphere vs the terminal velocity predicted from the SAME box's
                        drag measured with the SAME (reaction) force, plus the total-momentum
                        diagnostic. With the reaction force the action-reaction gap is zero by
                        construction. Needs dem + coupling on PYTHONPATH.

- fresh_cell_gate.py   the moving-boundary force-spike study: Seo & Mittal 2-delta metric + a
                        5-harmonic residual, dt/h/amplitude legs, fresh-cell seeding off vs on.
                        Seeding (default ON since flow 1a01769) removes a resolution-independent
                        +2.6..2.9% drag bias and 20-50x of spurious oscillation.
- rotation_gate.py      THE TORQUE GATE (flow 16e91ec). A: static spin vs the exact 8*pi*mu*a^3*Om
                        -- was a structural -31% (Laplacian-form budget missing mu*(n x Omega),
                        exactly 1/3), now +3.5/+2.4/+2.2% CONVERGING; net force must stay ~1e-13.
                        B: spin-decay through ResolvedCfdDem apply_torque=True vs the same box's
                        calibrated drag (1.039 measured). ROT_STATIC_ONLY=1 skips B;
                        ROT_FULL=1 adds the N=128 rungs. Needs flow (+dem+coupling for B).

## Composed particles (§6.5)
- scene_particle_gate.py  dem SHAPE_SCENE vs the same shape as a fine grid bake, at

                        the tree is exact and the grid is the approximation). Needs

depth 4 — the "coarse" solve is left on the full grid. Fine on CPU; a 50x tax on GPU.

## 2026-09-02 — geometry & finite-Re gates (ten Cate campaign close-out)
- `galilean_re_gate.py [DH] [Re] [N] [STEPS]` — finite-Re Galilean pair: towed sphere vs fixed sphere
  in a stream (`set_velocity`), same impulsive start + body force. PASS = quasi-steady drag within 2%.
  Measured: 0.03% (Re 1.5, d/h 8), 0.9% (d/h 12), 2.1% (Re 30).
- `duct_re_gate.py [DH] [Re] [STEPS]` — static twin of the settling tank: fixed sphere, duct walls
  translating with the plug. Duct Cd/Abraham 1.30 → 1.08 → 1.06 at Re 0.015 / 1.5 / 30 (screening).
- `periodic_image_gate.py` — a CSG slab wider than the periodic box refills its own cavity (images are
  a UNION); `periodic_image_overlap_cells()` must flag it (43 680 cells) and read 0 for L/2 + wall.
- `lattice_plane_gate.py` — a moving face exactly on a grid plane is inert (sdf == 0 at staggered
  points: fluid to the mask, not a ghost to the fold); `moving_instance_degenerate_points()` must
  count 4 096 there and 0 for the 0.3-cell-shifted plate (which moves the fluid).
- `csg_wall_velocity_gate.py` — wall velocity on a CSG difference instance holds a plug exactly
  (momentum fraction 1.0000 over 100 steps; 0.44 with walls at rest). Run with an argument for the
  two-instance ordering variants.
- `cutwall_*.py` — the ten-cate probes (free-fall trace, Newton audit, tow drag, periodic control),
  tank slab now L/2 + 1 (the 0.7 L slab was the trap).
